The defaults that separated the strong rounds from the competent ones — written portable so any capable model reaches the same level.

## The operating loop
**Ground → Diagnose → Legislate → Build → Verify → Flag.** Re-read the conversation before designing; name the root cause as a system statement before touching pixels; every fix produces a reusable law; never present unverified work; end by naming the riskiest element and its one-line undo.

## Choreography
One composed timeline, not many animations. FLIP hand-offs for identity continuity. Word-level headline stagger. Motion that *means* something nameable.

## Interaction
Compose multiple behaviours (breathe + proximity + pulse) in **one rAF loop** with per-item state — never stacked CSS animations fighting over properties. Pause off-screen and when hidden. IntersectionObserver as a positioning system.

## Design-system thinking
Registers (volume control). Signature protection by prohibition. Ornament vs meaning. Accent budgeting. Documentation that shows (rendered do/don't pairs). Honour the user's latent system — excavate before inventing.
