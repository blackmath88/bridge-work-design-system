The construction rules

Eight rules. No exceptions.

Otl Aicher's discipline married to the bridge-work grammar. The rules are what make a new mark belong without anyone art-directing it.

01 · angles
0° / 45° / 90° only
Every stroke is horizontal, vertical, or a true diagonal. No other angles exist in the language.
02 · weight
Uniform bold, round caps
One stroke width across the whole mark (7 on a 120 grid). Round line caps, always.
03 · colour
Teal structure
All stroked structure is teal. Geometry is never ink, grey, or white. This is law.
04 · curves
Curvature never stroked
The signature rule. Curves enter only as filled forms — a solid disc, a filled quarter-arc, a filled leaf. Aicher curved his strokes; we never do.
05 · accent
One solid accent
Exactly one filled accent element = the activated thing (the engaged user, the current step, the signal). Amber by default; see §accent.
06 · meaning
The name-it test
A viewer must be able to say what it depicts. If they can't, it's ornament — and ornament never sits where an icon belongs.
07 · UI glyphs
May be stroke-only
Pure interface glyphs (close, plus, menu chevrons) have nothing "activated" — they may omit the accent and be stroke-only.
08 · arrows
No triangle heads
The triangle isn't in the alphabet. A bridge-work arrow is a stroke ending in a solid destination disc — movement toward the signal.
Accent (structure stays teal):
Context-accent rule: structure is always teal; the one accent takes the context colour. Amber = public / default · cyan = connect-flavoured · violet = govern-flavoured · rose = never (semantic/earned only, reserved for the Signal Mark and true "active" states). For an M365 onboarding tool, amber is the safe default; use cyan if you want a "collaboration/connect" feel. Switch the swatch above to recolour every mark on this page.

How to extend · the checklist

Every new mark, five checks.

  1. 1
    Name it in one word before drawing. If you can't, it's not a pictogram. Decide the one activated element — that becomes the single solid accent.
  2. 2
    Build structure from strokes at 0/45/90 only, teal, weight 7, round caps. Containers = stroked rects/lines. Keep endpoints on a mental grid.
  3. 3
    Add curves only as fills — disc (D), quarter-arc (ARC), or leaf (LF). Never a stroked curve. A round corner radius on a rect is fine; a curved line is not.
  4. 4
    One accent, context colour. Amber default. The accent marks what's active/engaged/current — never decorative, never two.
  5. 5
    Size-test at 24px. If strokes merge or it becomes unreadable, simplify — fewer elements, larger gaps. Then run the name-it test on a fresh pair of eyes.
Hard limits (never): no stroked curves · no triangle arrowheads · no ink/grey/white geometry · no second accent colour in one mark · no 2×2 of four solid squares (that's the Signal Mark's exclusive signature) · rose accent only for genuine "earned/active" states, not decoration.
When in doubt, copy a neighbour. The starter set covers most onboarding needs; a new mark is usually a small edit of an existing one (mailbox → calendar, person → person-with-badge). Reuse the composition logic.
